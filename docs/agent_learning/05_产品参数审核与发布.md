# 第 5 课：产品参数审核与发布

## 1. 为什么需要审核层

PDF表格可能错列、单位混乱，不能直接写入销售产品库。

```text
PDF表格 → 参数候选 → 人工审核 → 正式产品参数
```

## 2. 数据放在哪里

- `document_tables`：PDF表格的Markdown和行列JSON。
- `product_spec_candidates`：待审核参数、来源页、原文和置信度。
- `product_spec_values`：审核并发布后的正式参数。

## 3. 如何使用

在知识库管理页：

1. 点击“从PDF表格生成”；
2. 检查字段键、类型、值和单位；
3. 点击“通过”或“拒绝”；
4. 输入型号，点击“发布已通过项”。

发布使用数据库事务，失败时不会留下半套数据。
