# 09 回答质量评测

## 目标

检索命中正确文档，不代表最终答案一定可靠。回答质量评测检查大模型有没有正确使用证据。

## 四个指标

| 指标 | 检查内容 | 门槛 |
|---|---|---:|
| Answer Relevance | 是否直接回答问题并覆盖关键点 | ≥ 0.80 |
| Faithfulness | 回答事实是否都能被证据支持 | ≥ 0.85 |
| Citation Completeness | 关键事实是否带有效的 `[n]` 引用 | ≥ 0.80 |
| Refusal Correctness | 资料不足时是否正确拒答并说明下一步 | ≥ 0.90 |

## 执行流程

`问题 → 草稿generation检索 → 生成带引用回答 → 大模型裁判 → 四项门禁`

评测集包含 12 题：9 题正常问答，3 题专门测试价格、SAR产品和同步精度等资料不足场景。

## 存放位置

- 评测题：`storage/rag_answer_eval_set.jsonl`
- 门槛：`config/rag.yaml`
- 完整报告：SQLite 表 `kb_generation_answer_evaluations`
- 接口：`POST /api/rag/answer-eval`
- 查询版本报告：`GET /api/rag/generations/{id}/answer-evaluation`
